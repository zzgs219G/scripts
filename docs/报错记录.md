── 🔧检查更新 ───────────────────────
  up         一键检查更新/自动升级《焚诀》
── 🔧 初始化 ────────────────────────────
  setup    检查环境 + 配置 Git 全局信息
  login    登录 GitHub（浏览器/Token）
  repo     创建远程仓库
  remote   管理远程地址（增删改查）
  trust    信任当前目录（safe.directory）
  aikey    配置 AI commit key（Anthropic）

── 📂 项目导航（书签制·方向键）──────────
  bookmark  管理书签（增删改查）
  lsp       所有书签项目状态总览
  c         书签→项目→操作 交互导航（↑/↓+回车 选择）
  c <名字>   书签/项目关键字直达
  cl         交互式克隆（gh 仓库列表选择）
  cl <仓库>  直接克隆到当前目录/指定书签
  pullall   批量拉取所有书签项目
  pullall <书签> 只更新指定书签

── 🌿 分支操作 ──────────────────────────
  b all      打捞全部远程分支并本地镜像
  b          列出分支 → 选编号切换
  b <名字>   直接切换/创建分支
  b -l       显示所有分支（含远程）
  b ql       清理分支缓存
  b -d <名>   删除本地分支
  b -dr <名>  删除远程分支
  gomain     回到 main/master
  rn         重命名当前分支（本地+远程）
  bclean     清理已合并的本地分支

── 🚀 推送 & 发布 ───────────────────────
  p          推送（自动检测远程新提交防冲突）
  p 远程名   推送到指定远程（如 p cnb / p gitee）
  p skip     可跳过CI构建
  p "备注"   指定备注推送
  remote     绑定远程（GitHub/GitLab/Gitee/CNB/CODING）
  gsync      安全同步远程（fetch+rebase）
  pull       拉取最新代码
  ok         合并 dev→main 发布
  ok dev main skip  合并 跳过 CI 构建
  no         撤回最后一次发布 ⚠️ 危险

── 📊 查看 & 对比 ───────────────────────
  st         当前分支 + 变更文件数
  info       仓库完整信息（含领先/落后）
  rls 用户/仓库 查看远程仓库文件列表
  lg         提交历史图（默认15条）
  lg 30      查看30条历史
  d          查看未暂存的变更
  d s        查看已暂存的变更

── 🧰 实用工具 ──────────────────────────
  save       暂存工作区
  pop        恢复暂存
  fix        冲突解决引导
  tag        查看所有标签
  tag v1.0   发布版本标签
  f          全量打包源码（滤掉垃圾，喂给AI）
  f <模块>    只打包指定模块
  f -d       只打包未提交的改动
  undo       撤销工作区所有修改 ⚠️
  unstage    取消所有暂存
  h          显示此菜单
